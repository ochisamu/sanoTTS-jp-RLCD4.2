Modified files: firmware/main/echo_dsp.c and echo_dsp.h translate the
CharaDock processor into C float arithmetic at 22050 Hz, with fixed-size
state/tail storage, invalid-state handling and a legacy comparison mode.
tests/reference_atom_echo.cjs retains the relevant JavaScript DSP excerpt
with only a standalone export and attribution wrapper.
Transport design references: stereo duplication, larger DMA queue and drain.
The firmware uses ESP-IDF 5.5.4's I2S channel API instead of the legacy API.
