# RLCD4.2 日本語オフライン音声ラボ

[English](README.en.md) · [再現手順](docs/REPRODUCE.md) · [学習元](docs/TRAINING.md) · [ライセンス](licenses/README.md)

**Powered by Moonshine AI**

Waveshare ESP32-S3-RLCD-4.2（Flash 16MB / PSRAM 8MB）で、日本語の音声認識・
短文の返答生成・sanoTTS-jpによる読み上げを動かす独立した研究プロジェクトです。
推論は端末内。クラウドAPI・Wi-Fi・PCでの音声生成は使いません。
PC/GPUは学習・書き込み・任意の文字入力に使用します。
CharDock・既存のATOM Echoデモとは別プロジェクトです。

**未完成の実験版です。一般会話の品質・低遅延・電池単独での長時間動作を保証しません。**
現在の対話モデルは無関係な回答や否定の取り違えがあり、品質基準を満たしていません。
モデル重みと統合flashイメージは公開準備の対象から外しています。
モデル非同梱のファームウェアについては[Releaseの導入条件](docs/FIRMWARE_RELEASE.md)を参照してください。

## 操作と画面

| 操作 | 動作 |
| --- | --- |
| KEYを押して離す | 5秒録音 → 音声認識 → おうむ返し |
| BOOTを押して離す | 5秒録音 → 音声認識 → LMで返答生成 → 読み上げ |
| PWR | 電源操作のまま |

通常起動後、録音表示が出たら話してください。BOOTを押したまま起動すると
ダウンロードモードに入ります。起動時・処理中の押しっぱなしと同時押しは無視します。
待受中の常時録音はしません。新しい質問で会話履歴を引き継ぐ機能はありません。

画面は東雲16ドット（6,974字形）と独自のシンプルな顔を使用します。
大きな顔と英語ステータスを中心に、必要なときだけ下部に日本語字幕を表示します。
`HEARD` は認識したかな、`REPLY` は復唱文または返答です。
既知の回答149種類は漢字字幕に対応。未対応の自由文はかなのまま表示します。
字幕は3行、長文は待機中に4秒ごとにページ切替。処理終了後およそ8秒で消えます
（長文はページ数に応じて延長）。内部の文は次の操作まで保持します。
音声は低中域のこもりを抑えるEQを適用。増幅量・音量上限は上げていません。
漢字の字形表示には対応しますが、**STT/LMが漢字文を生成するわけではありません**。
未知の字形は四角で表示します。Stack-chanの画像・コードは使用していません。

Windowsは `tiny_lm/console.cmd`、その他は以下で文字入力も試せます（pyserialが必要）。

```sh
python -X utf8 tiny_lm/console.py --port YOUR_PORT --say
```

かな最大80文字。例: `かんたんなりょおりおおしえて`。`/quit`で終了。
`きょお`など発音寄りのかなが学習形式に合います。漢字入力・任意の知識検索には非対応。

## 処理構成と測定値

マイク → 無音除去・音量調整 → 6層音素CTC → かな →
〔KEY:そのまま / BOOT:端末内知識16項目、一致しなければ4層生成LM〕→ sanoTTS-jp → DSP → スピーカー。
録音・認識の一時領域を解放してからLMを読み込み、LMを解放してからTTSを実行します。

| 項目 | 実測・構成 |
| --- | --- |
| STT | Moonshine由来6層、41音素、W8A8、7,808,724 bytes |
| STT時間 | 保存済み6.6秒音声に約13秒。短い実発話とは条件が異なる |
| 対話LM | 4層・幅256・約291万パラメータ、BPE 1,024語彙、W8A8、3,074,496 bytes |
| LM時間 | 32件で約1.0–1.9秒。録音・STT・TTSを含まない |
| TTS | sanoTTS-jp v1.0.0 / v4 INT8、654,032 bytes |
| 音質 | CharaDock由来DSPをRLCD向けに調整。音量・速度の設定を維持 |
| 表示 | 400×300・1bit、15,000-byte framebuffer、約251KBのFlash字形 |

32件のLM出力一致は「PC参照実装との一致」であり、正答率100%ではありません。
音声認識のdev音素誤り率14.49%、追加学習後のLM言い換えdev完全一致115/175も、
独立した最終テストや実環境の会話精度ではありません。詳しくは[学習元と評価](docs/TRAINING.md)。
[漢字字幕・追加学習・知識集の仕組みと再現手順](docs/REPLY_UPGRADE.md)。
